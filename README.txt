NORTHSTAR CALCULATOR

To run:
1. Open this folder on your Desktop.
2. Double-click index.html. It opens in your default web browser and works offline.

Features:
- Standard arithmetic and scientific functions
- Degrees/radians angle mode
- Keyboard input: Enter to calculate, Esc to clear, Backspace to delete
- Memory controls and calculation history saved in this browser

No installation or internet connection is required.
